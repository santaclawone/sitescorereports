Meta descriptions

A meta description is an HTML attribute that summarizes a page's content. It appears below the title in search results and influences whether someone clicks your listing.

Do meta descriptions affect rankings

Google has stated that meta descriptions are not a direct ranking factor. However, they significantly impact click-through rates, and click-through rate is a strong user engagement signal that search engines do consider.

A compelling meta description can increase your CTR by 5-15%. For a small business competing locally, that translates directly to more visitors and more leads.

How to write effective meta descriptions

Include your target keyword naturally. Keep descriptions between 150-160 characters � longer text gets truncated in search results. Make each description unique across your site. Include a clear value proposition or call to action.

Example: Get a free website audit for your Irish small business. SEO, performance, mobile, and security checks delivered to your inbox in minutes. This description includes keywords, states the value, and ends with an implicit CTA.

Common problems

Missing meta descriptions force search engines to auto-generate snippets from page content, which are often incoherent. Duplicate descriptions waste an opportunity to differentiate pages. Description length outside the optimal range gets truncated or appears sparse.
